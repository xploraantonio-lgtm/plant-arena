# Farming UI assets

The PvP/farming UI expects these transparent assets:

- `water.webp`
- `fertilizer.webp`
- `shovel_fragment.webp`
- `scarecrow_fragment.webp`
- `pesticide.webp`
- `shovel.webp`
- `scarecrow.webp`
- `gold_coin.webp`

The React UI includes emoji fallbacks, so missing art never blocks gameplay or build validation.
