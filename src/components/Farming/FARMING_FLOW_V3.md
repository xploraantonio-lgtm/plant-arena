# Farming Flow V3 local demo

This local-only playground covers the full UX cycle without backend economic writes:
- start with no Lands/rentals
- buy a Genesis Land
- enter system/NPC Lands before owning anything
- rent free slots for 7/15/30 days
- configure owned slots as personal or listed for rent
- plant one of 2 mystery seeds
- apply 5 separate watering actions
- apply up to 2 fertilizer actions
- help water NPC crops
- trigger/capture crow events and receive local demo Gold drops
- use gaming popups instead of browser alerts

State is persisted in localStorage under `plant-arena-farming-flow-v3` and can be reset from the Farming home screen.
